## 📚 技术要点

### 权限控制分级
- 基础操作（查询、详情、状态、更新信息）：SUPER_ADMIN, DEV_ADMIN, OPS_ADMIN
- 敏感操作（重置密码、删除、恢复）：SUPER_ADMIN, DEV_ADMIN

### 表单对话框模式
```tsx
const [modal, setModal] = useState({ open: false, userId: "" });
const [form] = Form.useForm();

// 打开对话框时设置初始值
setModal({ open: true, userId: record.id });
form.setFieldsValue({ field: record.field });

// 提交时验证并调用 API
const values = await form.validateFields();
await API.update(modal.userId, values.field);
```

## ⚠️ 注意事项

- 所有操作完成后需调用 `loadData()` 刷新列表
- 超级管理员账号（ADMIN_USER_ID）禁止禁用和删除
- 删除用户是软删除（设置 deleted_at），可通过恢复功能还原
- 前端表单验证：手机号必填，邮箱需符合格式
- 微信绑定功能预留接口但前端暂不支持
