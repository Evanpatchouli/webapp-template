## 📚 技术要点

### 权限检查方式
1. 工具函数: `hasPermission()`
2. Hooks: `useHasPermission()`
3. 组件: `<AuthWrapper>`, `<AuthButton>`, `<AuthRoute>`

### 数据流
```
后端 migrator → 数据库 → 登录返回 roles/permissions
→ Zustand store → 权限检查 → UI 控制
```

## ⚠️ 注意事项

- 前端权限仅用于 UI 控制，真正验证在后端
- 权限编码大小写敏感，统一使用大写+下划线
- 超级管理员拥有所有权限
